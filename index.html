gog-mail

gog-mail is a personal, single-user automation tool. It uses the Gmail API to read and organize the mailboxes of its own owner (search, labels, archive) so that routine mail cleanup and reporting can run unattended on the owner's private server.

It is not offered to the public, has no sign-up, and does not collect data from any other users.
